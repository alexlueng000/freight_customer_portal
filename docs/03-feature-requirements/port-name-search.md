# 客户运价查询：地名搜索与中文显示

2026-09-09，依据用户反馈及 V1.1 PRD 的“深圳→洛杉矶”验收场景。

- 客户查询支持中文地名、英文名和港口代码，不要求客户记忆代码。
- `GET /api/v1/portal/rates` 新增可选 `pol`、`pod` 关键词，各最多 150 字；中文常用港口映射、英文名称包含匹配和代码匹配均在服务端执行。
- 原 `polCode`、`podCode` 精确过滤继续兼容；同时提供关键词与代码时取交集。起运地、目的地、有效期和租户条件也取交集。
- 返回值增加 `polDisplayName`、`podDisplayName`，结果列表、移动端列表及报价申请摘要优先显示中文，代码作为辅助信息。保留原名称、代码及报价快照。
- 当前中文目录覆盖 19 个现有常用地点，不是全球港口全集；未知代码保留运价原名称。不会依据城市名称猜译某个具体港区或改写存量运价。地名匹配范围以目录与已录入名称为准。
- 结果仍只来自当前租户的有效运价，保留客户状态检查、价格权限及服务端分页；没有数据库迁移。

验证覆盖中文/英文/代码、未知地名、空白、长度限制、SQL 通配符、起讫点组合及跨租户隔离。
