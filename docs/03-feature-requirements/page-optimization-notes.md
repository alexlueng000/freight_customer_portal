# 逐页优化记录

## 2026-09-09 — 删除未使用的运价

- 状态：已修改代码；按用户要求未运行测试。
- 运价列表增加红色「删除」按钮，点击后确认运价编号、航线和不可恢复的影响。
- 未被任何报价引用的运价允许删除，箱型价格和附加费随主记录一并删除。
- 已被报价引用的运价禁用删除入口，显示「已用于报价，只能停用」；不按报价状态放宽删除。
- 后端新增 `DELETE /api/v1/rates/:id`，要求 `rate.manage`，检查租户归属，并在事务中锁定运价后检查引用，避免与创建报价发生竞态。
- 删除与 `RATE_DELETED` 审计记录在同一事务完成；已引用返回 `RATE_IN_USE`，不存在或跨租户返回 `RATE_NOT_FOUND`。
- 复用现有外键级联规则，无数据库迁移；不会主动清理现有运价，需用户逐条确认。

## 2026-09-09 — 运价 Excel 导入减轻操作负担

- 状态：已修改前端代码；按用户要求未运行测试。
- 用户反馈：智能导入界面太重，用户可能不会使用。
- 调整：首次只展示选择文件、拖放区域和辅助模板链接；读取完成后切换到运价核对，导入后仅显示结果。
- 核对重点：航线、船司、有效期、采购成本、标准售价和附加费；去掉识别评分、重复摘要和步骤栏，导入按钮按运价条数表达。

- 前台取消「旧版导入方式」分支，保留已有后端接口；正常入口统一经分析、预览和确认后导入。保留格式记忆配置、阻断错误及提醒确认。
- 无数据库变更；本次仅调整前端交互，不新增解析能力。

## 2026-09-09 — 创建与编辑客户的税号字段不一致

- 状态：已核实并记录，待实施；本次不修改页面代码。
- 用户反馈：创建客户时没有税号，编辑客户时却出现税号。
- 代码核实：新建页 `apps/web/app/admin/customers/page.tsx` 没有税号输入及提交字段；详情页的编辑表单包含 `taxId`；后端创建 DTO 和服务已支持可选税号。因此当前差异来自前端表单字段不一致。
- 建议修正：新建客户补充可选「税号」字段并提交给现有接口，与编辑表单保持一致；允许创建时留空、后续补充，避免用户为填写税号必须保存后再次编辑。
