# 改价时提供客户可见说明

2026-09-09：内部改价原因与客户说明分别录入，避免公开内部成本、利润或议价记录。

- 销售改价窗口新增必填的“客户可见报价说明与条款”，初始化为当前报价条款，提醒保留已有约定。
- 沿用 `customerTerms`，与价格在同一事务保存并写入改价审计。不会新增费用项。
- `PATCH /api/v1/admin/quotes/:id/prices` 接受可选 `customerTerms`（去除首尾空白后 3–2000 字）；旧客户端省略时保留原条款。
- 正式发布后，客户在“报价说明与条款”查看，现有 PDF 条款区使用同一字段。草稿价格和说明仍不对客户公开。
- 不自动公开历史内部改价原因，不改写已发布报价。无数据库迁移，权限和租户边界保持原有规则。

验证：数据库改价保存、发布后客户读取及 PDF 数据、内部原因不泄露；桌面与移动端编辑和保存说明。
