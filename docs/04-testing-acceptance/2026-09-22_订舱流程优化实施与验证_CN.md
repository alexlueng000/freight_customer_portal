## 已实施内容

1. 用户界面、相关通知与本轮文档将 SO 表述为“订舱确认单”；协议中的 `SO`、`so-records`、模型名保持兼容。
2. 登记表单增加预计到港、集装箱进港截止、补料截止、核实总重申报截止、码头和实际接收时间。可选未知信息为空，不自动用上传时间代替接收时间，不用报价计划开船时间填充确认日期。
3. 输入采用明确的 UTC 偏移，默认北京时间；展示明确标注北京时间 UTC+08:00，数据库存 UTC。已有租户 timezone 字段未变更，本轮未实现自动按港口推断时区。夏令时由操作者按原单日期核对偏移。
4. 发布前展示确认单结构化信息和附件摘要；新增修订入口。修订会创建新版本，原已发布版本在新版本发布前继续供客户查看。
5. 修复内部/客户确认单列表误用查询字段的问题：内部可见来源、操作者；客户响应不再返回来源名称及内部操作人。
6. 服务端从最高有效确认单版本初始化运输的船司、船名、航次、预计开船/到港，忽略旧客户端传入的这些事实值。可传入预期确认单 ID，过时则返回冲突。缺项保留未知，不回退报价船期。
7. 内部订舱详情可核对确认单与运输计划差异，明确选择需要更新的字段。仅 PLANNED 运输允许此动作，执行/终止阶段只读；确认单版本或运输更新时间改变时拒绝旧请求。更新不触碰实际开船/到港时间，并记录操作者、版本和前后值。
8. 提交及重提原子保存独立委托版本、提交人、提交时间和白名单快照。草稿编辑与提交使用相同的订舱行锁，避免提交快照与编辑内容交错。提供每页 20 条的历史查询及版本选择、打印/另存 PDF 入口。
9. 提交确认摘要补全货物、包装重量、发货人、联系人、申请服务和地点，并区分计划日期及已接受报价条款。客户当前阶段提示区分确认单已收到待发布、已发布、已建运输，加载失败不显示为空记录。

## 数据与接口

新增迁移：`prisma/migrations/20260922090000_booking_submission_versions/migration.sql`，已在本地数据库应用。

- Booking 新增 submissionVersion 计数；BookingSubmission 保存不可覆盖的提交快照。
- 租户/订舱/版本联合唯一约束支持历史分页与并发版本保护；旧数据不伪造历史快照。
- 提交快照、状态和审计同一事务提交。运输创建及确认单登记/发布通过订舱行锁协调；并发版本冲突返回明确错误。
- 新增 `GET /api/v1/bookings/:id/submissions` 与内部对应路径，沿用 booking.read 并执行公司/租户过滤；`before` 查询更早版本。
- 新增 `GET /api/v1/shipments/:id/confirmation-difference` 和 `POST /api/v1/shipments/:id/sync-confirmation`，要求 shipment.manage，服务端限定内部及租户/销售范围。
- Swagger 补充历史查询、差异核对、受控更新及运输建档语义。

部署时先应用新增迁移并生成 Prisma Client，再更新 API/Web。已有数据库记录、已接受报价、旧确认单均保留。当前只更新本地环境，没有生产部署。

## 环境修复与剩余工作

- 原 Playwright 启动命令使用 POSIX 内联环境变量，Windows 无法执行。已改为 Node 命令与 Playwright env 配置；HTTP 专项配置只访问运行中的 API，不启动网页或浏览器。
- 原 Worker 测试脚本未启用其配置要求的 ESM 模式，且 PDF 测试引用未声明的包。改用 Jest 注入的 import.meta.jest 与 ESM 启动参数；PDF 汇总函数补充元组返回类型，使已有类型检查可通过。
- 网页服务启动时沙箱拒绝创建构建目录；后续权限请求未获批准，未继续尝试绕过。因此本轮最终不能称为“全部验收完成”。API/Worker 已恢复运行；网页服务需恢复后再测。
- 原需求提到取消、变更及交接的待定规则仍未定，第二轮 B1–B4 未实施。
- 明确采用保守的 PLANNED 同步限制；已开船、到港、取消记录不通过本次新动作修改计划。业务人员应在 UAT 核对该限制。

恢复网页服务后，执行客户订舱、建运输弹窗、pilot-delivery、golden-path、角色权限的浏览器测试，并以客户和操作员账号核对下面四件事：

2. 发布摘要包含三类截止、接收时间与附件；修订待发布时客户仍只能下载旧有效版本。
3. 委托第 1/2 版可切换，打印/另存 PDF 仅包含所选委托；中文、分页、长文本不截断。
4. 不同权限账号访问历史/打印数据和差异接口均符合权限；页面错误可重试，终态不提示继续正常流程。
