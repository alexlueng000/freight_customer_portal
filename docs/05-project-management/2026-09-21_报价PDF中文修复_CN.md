# 报价 PDF 中文修复

## 原因与修改

- PDFKit 默认 Helvetica 不含中文字形，导致客户名称、费用名称及条款乱码。
- Worker 打包 Noto Sans CJK SC Regular 与 OFL 许可证，正文嵌入中文字体；路径相对模块解析，不依赖系统字体或运行时下载。
- Docker Worker 镜像复制字体资源。自定义部署需同时分发 `apps/worker/assets` 和 `dist`。
- 费用行按文字实际高度排版，跨页重复表头；总额空间不足时换页，条款分页预留页脚空间。
- 对客 PDF 费用列不再输出 OCEAN_FREIGHT / MANUAL_CHARGE 等内部代码。
- API 对象存储路径和 BullMQ jobId 增加 `cjk-v2` 模板版本，绕开旧乱码 PDF 缓存，不修改报价业务版本，不删除历史文件。

## 生效与验收

- 需要 API 和 Worker 都加载新代码；容器部署需重新构建相应镜像。
- 再次下载原报价会请求新模板 PDF；之前下载到电脑上的旧文件不会自动改变。
- 无数据库迁移，不更改报价费用、条款内容、客户权限或租户隔离。
- 已调整 Worker 测试输入为中英混合客户名、中文费用及条款，并增加字体嵌入、Unicode 映射断言。
- 遵照用户先改代码、统一测试的要求，未运行测试、typecheck、lint、build，未生成或渲染 PDF 样张。已检查代码差异和字体 SHA-256；中文显示、长条款、多页费用及重新下载仍需统一验收。
