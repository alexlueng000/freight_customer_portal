# 客户首页布局与分区优化

- 修正运输、通知被嵌套进待办面板的问题：桌面为两个独立并列栏，左侧待办，右侧运输与通知；小屏幕按同一阅读顺序堆叠。
- 待办使用浅橙色标题区、运输使用浅青色、通知使用浅蓝色，搭配同色细边框；统计入口增加淡色背景，标题文字仍明确标识分区。
- 待办默认展示 5 条，可展开接口已返回的其余记录；通知默认展示 3 条，可展开更多已返回通知。保留完整业务列表入口。
- 订舱与运输统计入口改为完整列表，避免原有单一状态筛选漏掉统计包含的其他状态；说明文案明确跳转范围。
- 调整待办操作的排列，在空间允许时与说明并排，小屏幕自动换行。
- 沿用现有接口、权限与租户隔离；无数据库迁移，无后端业务规则变化。
