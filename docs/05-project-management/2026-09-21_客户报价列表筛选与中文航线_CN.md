# 客户报价列表筛选与中文航线

日期：2026-09-21。

## 改动

- 客户「我的报价」增加报价编号、状态、起运港、目的港及船司组合筛选，支持查询和重置。
- 筛选条件保存在 URL 中，查询／重置回到第一页。后端先筛选再分页，修复原状态筛选仅筛当前页的问题；总数与结果使用相同条件。
- 状态筛选考虑实际有效期，过期的待确认报价计入已过期，已接受报价不因有效期过去被误判为过期。
- 航线优先显示中文港口名，下方保留代码。复用已有常用港口字典，未收录港口回退来源名称或代码，不猜测中文译名。
- 港口查询支持中文、英文及代码；编号和船司支持不区分大小写的部分匹配，通配符按普通字符处理。
- 保留租户及客户公司隔离、未发布价格隐藏、原有创建订舱动作。无数据库迁移。

## 验证

- 新增数据库集成测试 3 项通过：组合筛选及分页、跨租户／同租户跨客户隔离、实际过期状态、中文名称、编号和空结果。
- 新增 Playwright 测试 2 项通过：1440px／390px 下航线展示、翻页后组合查询、重置、无结果提示及无页面横向溢出。页面测试使用模拟响应，持久化规则由数据库集成测试覆盖。
- API/Web 类型检查及 lint 均通过。

本次未调整报价金额规则和审批流程，工作区中其他既有变更保留。
