# 2026-09-21 报价费用编辑

状态：代码已修改，等待统一测试及用户验收。未运行测试、typecheck、lint 或 build，沿用用户先优化代码、之后一并测试的要求。

## 本轮行为

- 草稿报价增加「添加费用」，表内填写费用名称、计费方式（按箱／按提单／按票）、数量、成本单价、销售单价。
- 附加费用可以修改和删除，已保存费用在本次保存前可以撤销删除；所有修改仍统一「保存报价」，发布为独立操作。
- 海运费允许修改名称、成本和售价，其箱型、箱量及计费方式保留，禁止删除。原因是现有订舱创建依赖 OCEAN_FREIGHT 行继承运输需求。
- 成本留空表示待确认，利润概览不会将未确认成本当成零成本利润。
- 扩展现有 PATCH /api/v1/admin/quotes/:id/prices：已有行携带 itemId；新增行省略 itemId；删除通过 deletedItemIds 明确提交，省略的已有行继续保留以兼容旧调用。
- 后端使用 Decimal 重算行金额与总额，费用和报价字段、版本、审计在同一事务保存，校验租户／客户归属、草稿状态、费用 ID、数量、金额及基础海运费保护。
- 审计保留费用名称、计费方式、币种、数量、成本、售价、金额的前后快照及新增／删除 ID。
- 无数据库迁移。客户详情与 PDF 继续读取已保存的报价费用，成本及内部备注不进入客户费用数据。

## 明确边界

本轮沿用单币种 Quote 总额与 PDF 契约，新增及编辑费用须与 Quote.currency 一致。需求文档提出的混合币种报价、逐费用客户可见开关尚未实现；当前费用均为对客报价费用，成本仅内部可见。不做隐式换汇或跨币种相加。

- 草稿条款为空时，自动整理当前费用名称、计费方式、箱型及报价有效期；单价、数量和金额引用费用明细，不重复计算。
