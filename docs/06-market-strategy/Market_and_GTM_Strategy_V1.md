# 货代客户门户 SaaS V1 — 市场与获客策略

> 版本：V1.0（2026-08-29）
> 范围：市场分析、定位、定价、获客打法。产品功能范围以 PRD 为准，本文不涉及。

---

## 1. 产品定位

**不是货代 ERP**，而是货代公司面向客户的自助门户层：客户自助查运价、拿报价、下订舱、看跟踪、传单证、对账单。

核心价值主张：帮中小货代把客户服务体验数字化，不推翻其现有操作端系统。

三个差异化支点：

1. **白标（white-label）做成标配**——租户自定义品牌和域名。Freightify 把白标门户放在企业版，GoFreight 按用户数收费偏重，中间存在空档。
2. **Excel 运价导入 → 客户自助查价报价**——中小货代 90% 的运价在 Excel 里，把这条链路做顺就是入口。
3. **轻量门户层**——只做客户体验层，决策成本低、上线快，避开与全栈 ERP 正面竞争。

## 2. 市场规模

| 指标 | 数据 | 来源口径 |
|---|---|---|
| 全球货代管理软件市场（2026） | ~38 亿美元，CAGR ~9.4% | Morgan Reed Insights |
| 中国货代管理软件市场 | ~38-42 亿元/年，同比 +15.8%，SaaS 占比 >53% | 国内第三方综合 |
| 中国注册货代相关企业 | ~17.2 万家 | 行业普查口径 |
| 商务部备案货代企业 | ~1.87 万家（2025） | 备案口径 |
| 持 NVOCC 资质 / 一级代理 | 各约 1-2 万家次，占比 11-13% | 行业普查口径 |
| 北美货代 TMS 市场中小企业份额 | 62.5% | 北美 TMS 统计 |

> 注意：不同机构统计口径差异极大（全球市场另有 7.55 亿美元口径），以上数字用于方向判断，投资决策前需一手访谈验证。

**关键测算**：真正可服务的合规中小货代（备案 + 有正经客户群）约 5,000-8,000 家；客单价 ¥30,000-60,000/年 → **中国门户层 SAM 约 1.5 亿-4.8 亿元/年**。

**结论**：国内是"亿元级现金牛"市场，不是"十亿级指数"市场。要讲规模化故事必须出海或多市场。

**客群筛选红线**：2025 年全国货代投诉 12,743 件，72% 由无资质企业引发，80% 以上货代是无资质长尾（付不起、活得短、纠纷多）。**目标客户画像**：备案/持牌 + 10 人以上团队 + 50 个以上活跃客户 + 年营收 2000 万以上。

## 3. 竞争格局

### 国内：概念早已存在，是升级换代市场

"客户门户/网上营业厅"不是新品类：

- **货代大掌柜**：网上营业厅已覆盖在线订舱、提单确认、费用确认、货物跟踪、账单查询、运价查询——与本产品 V1 功能重合度 70%+
- **沃行 CargoWare**：线上询价（Web/API）、报价单模板、报价单转订舱、订单跟踪协同

它们的问题：UI 老旧、买断/项目制部署、移动端差、实施重。**国内定位 = 用现代 SaaS 体验做升级换代**，靠体验代差 + 订阅定价，而非功能清单。

### 海外：直接竞品与定价锚点

| 产品 | 定价 | 关键事实 |
|---|---|---|
| Freightify | Essentials **$999/月**（5 用户）、Standard $1,499/月 | 200+ 货代、45+ 国；运价管理 + 白标门户；自定义域名和 Track & Trace 在企业版 |
| GoFreight | 按用户订阅（demo 报价） | 1,000+ 货代客户、97% 美国港口覆盖；客户门户与 AI 能力（邮件建单、运价表识别、AI 报价）捆绑进基础订阅；深耕华人货代（美/台/港/东南亚）；实施 4-8 周 |
| Logitude World | $75-99/用户/月 | 唯一公开报价的 SMB 全栈 |
| CargoWise / Descartes | 企业级 | 不在中小货代射程内 |

**主要威胁**：GoFreight 在华人货代细分已扎根，且 AI 免费捆绑正系统性抬高品类门槛。
**GoFreight 的空档**：贵（per-user）、全栈太重、无陆运/铁路、英语为主。

## 4. 市场路线

| 路线 | 描述 | 判断 |
|---|---|---|
| **B：出海打华人货代（主攻）** | 美西/美东华人 NVOCC 数千家，付费能力已被 GoFreight 验证；用"轻门户 + 白标标配 + 有竞争力订阅价"打 GoFreight 与 Freightify 之间的空档 | **胜率中高，天花板高** |
| A：国内中小货代换代升级 | 存量认知已教育过，价格空间大；但需巷战，销售成本高，国内厂商代理网络深 | 胜率中，回款稳，天花板低 |
| C：平台化（货代的货代） | 白标门户演化成租户间互相给货给舱对账的网络平台 | 唯一十亿级故事方向，属 V3+，暂不投入 |

**最优路径：B 为主攻，A 为第二曲线现金流**。国内是出海产品的天然练兵场。

## 5. 定价模型

```
海外/出海货代：
  Starter   $299/月   5 内部用户 + 20 客户用户，标准品牌
  Growth    $799/月   白标 + 自定义域名 + 报价 PDF 模板（对标 Freightify $999）
  Scale     $1,499/月 无限用户 + API + 优先支持

国内货代：
  ¥1,999-3,999/月 订阅制（锚定大掌柜/CargoWare 年费摊薄）
```

原则：

- 定价杠杆放在**白标/自定义域名（品牌资产）、报价 PDF 生成量、客户用户数**
- 不要按内部用户数收重——货代团队规模波动大，是 GoFreight 被诟病的点

## 6. 获客打法（分阶段）

### 6.1 第一阶段：0 → 10 家设计合作伙伴（前 3 个月）

目标不是销售，是种子共创客户。

- **熟人网络找 3-5 家共创客户**：画像 = 10-50 人货代、50+ 活跃客户、老板亲自管报价、现用 Excel + 微信报价。给免费 12 个月 + 定制响应，换每周反馈、案例授权、转介绍。渠道：朋友圈、校友会、老乡商会（货代地域圈层极强：青岛帮、宁波帮、深圳华强北帮）
- **Fob 论坛（fobshanghai.com）**：中国最大货代论坛。先在"物流软件"版块回答问题攒信誉，再发"招募 5 家免费共创"帖。直接广告会被删

### 6.2 第二阶段：10 → 50 家精准名单销售（3-9 个月）

核心武器：**这个行业客户名单是公开的**。

1. **FMC OTI 名单（美国华人货代金矿）**
   - FMC 公开所有 NVOCC/货代持牌名单（OTI list），几千家，含公司名、地址、牌照号
   - 筛华人公司名，用 Apollo / LinkedIn Sales Navigator 补老板邮箱电话
   - 节奏：每周 100 封个性化邮件（提对方航线和痛点，标题参考："你们给客户报价还在用 Excel 吗"）
   - 配合 LinkedIn 搜 "freight forwarder" + 城市（LA、NJ、Chicago、Houston）

2. **商务部备案名单（国内 outbound）**
   - 各市商务局官网定期公布国际货代备案企业名单（含公司名地址），公开可查
   - 优先区域：深圳南山、上海虹口/浦东、广州白云、青岛
   - 国内不用邮件，用电话 + 微信；企查查补联系方式，销售加微信发 3 分钟产品视频

3. **货代联盟/协会会议（行业最有效的一对多场景）**
   - WCA First Conference（华人会员极多）、GLA 全球物流联盟（总部深圳，专做华人货代网络）、地方货代协会
   - 一次会议几百张精准名片，货代圈口碑传播极快；展位几万元一场，比广告便宜且精准

4. **展会**（优先级低于联盟会议）：慕尼黑上海物流展、中国国际物流节、深圳国际物流与供应链博览会

### 6.3 第三阶段：50 家+ 自获客管道（9 个月后）

5. **免费工具获客钩子（最重要）**：独立小工具页——"集装箱跟踪查询"或"报价单 PDF 在线生成器"，免注册可用一次，留邮箱保存结果。货代圈自发传播，流量导产品注册
6. **竞品替代关键词 SEO/SEM**：Google 投 "GoFreight alternative"、"Freightify pricing"、"freight forwarder customer portal"（搜索量小但转化率极高）；官网做诚实竞品对比页。国内百度 SEO 打"货代客户门户/在线报价系统/网上营业厅"（竞争极小）
7. **G2 / Capterra 上架**：给老客户 $50-100 礼品卡换真实评测，20 条进品类对比视野
8. **转介绍机制产品化**：推荐成交减免两个月月费；进一步把"给同行代理开放门户"做成功能，让产品长出网络效应

### 优先级（只做三件事）

1. FMC OTI 名单 + LinkedIn/邮件 outbound 打美国华人货代
2. GLA/WCA 联盟会议
3. 免费工具钩子 + 竞品对比页

### 两个坑

- **别零品牌时铺代理渠道**：国内软件代理需要品牌和案例先行，30 家客户后再启动
- **国内别烧百度竞价**："货代软件"流量多为同行和求职者，国内真实获客靠地推 + 会议 + 口碑

## 7. 风险清单

| 风险 | 说明 | 对策 |
|---|---|---|
| 国内功能重合 | 大掌柜/CargoWare 已覆盖 V1 清单七成功能 | 体验、白标深度、订阅定价做差异化；V1 功能是及格线不是卖点 |
| AI 门槛抬升 | GoFreight 已把 AI 邮件建单、运价表识别做成标配 | "运价 Excel 智能导入"排进 V1.5——这是入口功能 |
| 黏性短板 | V1 不做 EDI/船司对接/自动跟踪，跟踪靠手工录入里程碑 | V2 优先补跟踪自动化（技术与商务成本大头） |
| SMB 流失率高 | 货代行业周期性强，运价崩时先砍软件预算 | 年付折扣锁周期；聚焦合规、有客户存量的客户 |
| 天花板 | 纯门户层 ARPU 上限低 | 路线图在"门户"与"轻量 OS"间取舍，用白标网络化（路线 C）打开上限 |
