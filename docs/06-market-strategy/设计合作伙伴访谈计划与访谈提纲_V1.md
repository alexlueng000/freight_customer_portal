# 货代客户门户 · 设计合作伙伴访谈计划与提纲 V1

> **这份文档解决一个问题：把"我觉得他们会买"变成"我验证过他们会买"。**
>
> 产出目标：2 周内完成 3–5 家真实货代的深度访谈，拿到可对比的评分与承诺，形成 Go / Pivot / Kill 决策依据。
>
> 配套阅读：《10位顶级产品经理评审报告》（背景）、《老板模式产品方案》（Demo 素材）。

---

## 0. 三条铁律（先读这个，再读提纲）

1. **你在买信息，不是在卖产品。** 整场访谈你的角色是"学生"，不是"销售"。Demo 只占 25 分钟，其余时间都在听。
2. **只记录行为和事实，不记录客气话。** "这个产品挺好的" 一文不值；"上个月我们报错一个价，赔了 800 美金" 值千金。
3. **每次访谈结束前必须推进承诺阶梯**（见第 7 节）。没有下一步具体动作的访谈 = 白聊。

---

## 1. 访谈要回答的三个核心问题

| # | 问题 | 判断标准（什么算"通过"） |
|---|------|------------------------|
| Q1 | **痛点真不真**：报价/订舱/状态同步的混乱，是不是每周真实发生、有金钱代价的痛？ | 能讲出 ≥2 个具体事故（带金额/时间），且当事人仍在这个流程里挣扎 |
| Q2 | **替换意愿**：愿意把 Excel/微信 流程搬到新系统吗？愿意让客户一起用吗？ | 愿意指定 1 名员工配合试点 + 愿意邀请 2–3 家客户上门户 |
| Q3 | **付费意愿**：$299–1499/月 这个区间落点在哪？ | 给出 4 问定价测试的落点，且不出现"免费再说"式回避 |

**注意**：三个问题全部通过才继续投入；Q1 通过但 Q2/Q3 不通过 → 问题在"替换成本"与" perceived value"，调产品包装不调方向；Q1 都不通过 → 这批样本不对或方向有问题，先换样本再谈 Pivot。

## 2. 找谁：设计合作伙伴画像与筛选

### 2.1 目标画像（全部满足为最优样本）

| 维度 | 标准 | 为什么 |
|------|------|--------|
| 规模 | 8–50 人团队 | 太小没预算，太大已有系统 |
| 业务 | 海运整箱 FCL 为主，月 80–400 票 | 与 V1 范围精确匹配 |
| 客户 | 20–100 家活跃客户 | 够多样，能暴露真实场景 |
| 谈话人 | **老板本人 + 至少 1 名一线操作/销售** | 只见老板 = 只听到想象；只见操作 = 听不到预算 |
| 现状 | Excel + 微信 + 邮件管理业务，没有系统或只用表格 | 替换动机最强的群体 |
| 关系 | 愿意说真话的人（弱关系优于强关系） | 朋友会为了面子夸你 |

### 2.2 排除标准（出现任何一条，礼貌结束不深入）

- 正在实施或刚买了 ERP / 指定系统；
- 主营拼箱/空运/报关（V1 范围外，访谈数据会污染判断）；
- "你们能不能顺便做个 XXX"——需求发散型，会把访谈变成许愿池；
- 纯询价心态（只想白嫖 demo 给现有供应商压价）。

### 2.3 招募话术（微信/电话，照抄可用）

> "X 总，我在做一个专门给中小货代用的客户门户系统，客户可以自己查运价、下单、看出运状态，你们不用再一个一个微信回。现在不是推销，我想找 3 家做得比较扎实的货代，帮我看看这个东西做得对不对——大概占用你 1 小时，我请你喝咖啡。你那边负责报价和订舱的同事也在场最好，我想听听一线怎么说。"

**要点**：不说"免费试用"、不说"求推广"，定位是"请专家帮忙把关"——货代老板对这个角色受用。

## 3. 访谈前准备清单（每次访谈前过一遍）

- [ ] Demo 环境预热：种子数据已造好（≥20 条运价、5 票在途、3 张发票），**数据要像他家的业务**（深圳→美西/东南亚为主，币种、柜型符合）；
- [ ] 老板模式原型已加载（`output/货代客户门户_老板模式_高保真原型.html`）；
- [ ] 一张**他家真实格式的运价 Excel**（提前要，或现场让他打开电脑）——用于 Excel 导入环节实测；
- [ ] 录音/录屏授权（开场口头确认一次）；
- [ ] 两人分工：一人主谈、一人只记录（行为信号表，见第 6 节）；
- [ ] 带纸笔，不带笔记本做记录（降低对方表演欲）。

## 4. 访谈结构（总计 90 分钟，严格控时）

### Part 1 · 开场与背景（10 分钟）

目的：建立"学生"人设 + 摸清盘子大小。

- 感谢 + 一句话定位："我不是来卖东西的，是想搞清楚你们的真实工作方式，看我做得对不对。"
- 求录音许可。
- 基本盘问题：
  1. 咱们公司多少人？销售几个、操作几个、财务几个？
  2. 主做什么航线、什么柜型？一个月大概多少票？
  3. 活跃客户大概多少家？最大的客户占多少成业务？
  4. 现在报价、订舱、对账分别用什么工具？（听关键词：Excel、微信、邮件、手写、某个系统）

> 🚩 红旗：如果第 4 问答出"我们用 XX 系统，挺好的"——记录系统名，后面 Q2 判断要打折。

### Part 2 · 现状流程复原（25 分钟）——全场最重要的 25 分钟

目的：让 TA 把"上周真实的一票货"从头到尾讲一遍。**不要问流程，问事件。**

开场指令：

> "能不能给我讲讲**最近一票**从客户询价到你们收到钱的完整过程？越细越好，最好具体到谁在什么时间做了什么。"

然后跟着时间轴追问，每个环节至少追问一次：

| 环节 | 必问追问 |
|------|---------|
| 询价/报价 | 客户怎么问的（微信？）？你在哪找到的运价？花了多久？发出去的报价长什么样（截图/翻记录给他看）？ |
| 定价决策 | 报价前要不要问老板/同行？加价怎么定的？拍脑袋还是有表？ |
| 订舱 | 客户确认后你们做什么？船东/同行怎么订？信息重填了几遍？ |
| SO/单证 | SO 怎么登记？客户怎么拿到提单副本？发错过吗？ |
| 状态同步 | 客户催进度一般怎么催？一周接几个这种电话/微信？ |
| 账款 | 对账怎么对？月底要花几天？逾期怎么发现的？ |

**关键技巧——"最后一次"问法**（把一般化回答逼成具体事实）：

- ❌ "你们报价容易出错吗？" → ✅ "**上一次**报错价是什么时候？怎么发现的？最后怎么处理的？赔了多少？"
- ❌ "客户经常催进度吗？" → ✅ "**昨天/上周**有客户问你'货到哪了'吗？你是怎么查到答案的？花了多久？"

### Part 3 · 痛点确认与代价量化（15 分钟）

目的：把 Part 2 听到的混乱，量化成钱和时间。

- 每个痛点追问三个数字：**频率**（一周几次）、**耗时**（一次多久）、**代价**（赔过多少/丢单没有）；
- 直接问排序："如果这些事里只能先解决一个，你先解决哪个？"（他的排序 ≠ 你猜的排序，记录差异）；
- 问替换的最大障碍："假设明天有个工具能解决这个，但你们要换掉现在的做法，**最难的一步会是什么？**"（听到的答案大概率是"我的人懒得学"/"客户不配合"——这决定你试点策略）。

### Part 4 · Demo 观察（25 分钟）

目的：不是讲解，是**观察他看哪里、问什么、皱眉还是身体前倾**。

顺序（刻意安排）：

1. **先看老板模式一屏**（5 分钟）：什么都不说，让 TA 自己看 30 秒，问"这一屏上，你第一眼看的是哪个数字？"——这个问题直接告诉你哪个指标该上老板 Dashboard；
2. **试一键动作**（5 分钟）：让 TA 亲手点"确认并发送"和"通过订舱"，观察有没有犹豫、有没有先找明细；
3. **运价 Excel 导入**（10 分钟）：**用他自家的 Excel 现场导**。这一步是 UAT-P0-013 的真实验证——如果导不进，当场记录他说什么（不要辩解，说"对，这正是我们要修的"）；
4. **客户门户视角**（5 分钟）：切到客户登录视角，问"你觉得你哪个客户会用这个？哪个肯定不会？"

**纪律**：TA 批评功能时不反驳、不解释设计初衷，只追问："你说这里不对——那你们平时正确的是什么样？"

### Part 5 · 定价测试与承诺阶梯（15 分钟）

**定价四问**（Van Westendorp 简化版，按顺序问，别提前报你的价）：

1. 这个东西如果免费，你们会用吗？（不用 → 前面全白聊，追问为什么）
2. 一个月收多少钱你会觉得**便宜得可疑**、担心用不住？
3. 一个月收多少钱你会觉得**贵，但咬咬牙能接受**？
4. 一个月收多少钱你觉得**抢钱，绝对不买**？

记录 TA 给出的区间，与 $299 / $599 / $999 / $1499 四档对照，看他落在哪一档（注意问的是**人民币感知**，换算后再对照）。

然后走承诺阶梯（第 7 节），**当场拿到最低一级承诺**。

## 5. 关键问题清单（速查卡，访谈时放手边）

| # | 问题 | 探测什么 | 好信号 | 坏信号 |
|---|------|---------|--------|--------|
| 1 | 上一次报错价是什么时候，代价是什么？ | Q1 痛点真伪 | 有具体事故+金额 | "没有吧，都还行" |
| 2 | 一周花多少时间在"客户问进度"上？ | 状态同步价值 | 能报出小时数 | 从没算过 |
| 3 | 报价前你总要问谁？ | 老板瓶颈 | "都得问我" | 有授权体系 |
| 4 | 月底对账要几天？ | 财务痛点 | ≥2 天 | 半天搞定 |
| 5 | 如果只能解决一件事，先解决哪个？ | 优先级校准 | 与主链一致 | 指向范围外功能 |
| 6 | 换工具最难的一步是什么？ | 替换成本结构 | 说得具体 | "没什么难的"（不真实） |
| 7 | 你哪个客户会用门户？哪个不会？ | 双边采纳现实 | 能点名两类客户 | "客户都不爱折腾" |
| 8 | 咱们谁来做试点对接人？ | Q2 替换意愿 | 当场指名 | "回头再说" |
| 9 | 免费用你会用吗？ | 需求真伪基线 | 毫不犹豫 | 犹豫/附加条件 |
| 10 | 贵到不买的价位是多少？ | 价格天花板 | 给出具体数 | 回避数字 |

## 6. 观察者记录表（第二人专用）

访谈中只记事实和行为，每 5 分钟一行：

```
时间 | 说了什么（原话） | 做了什么（身体前倾/皱眉/打断/掏手机拍照…） | 对应问题编号
```

**高价值行为信号**：

| 行为 | 解读 |
|------|------|
| 主动掏手机拍屏幕 | 真想要，回去要给人看 |
| 打断你开始讲自己的流程 | 触到了真痛点 |
| 身体前倾 + 连续追问某个功能 | 强兴趣点，记录是哪个 |
| "这个能不能顺便……"（发散许愿） | 中度兴趣但需控场 |
| 看老板模式时先找"钱"的数字 | 老板 Dashboard 的指标答案 |
| 沉默/礼貌微笑/"挺好的" | 无兴趣或碍于面子，不计入正面证据 |
| 主动问"多少钱" 且不等你说就猜价 | 付费意愿强信号 |

## 7. 承诺阶梯（访谈结束前必须爬一级）

从低到高，**当场拿到能拿到的最高一级**：

| 级别 | 承诺内容 | 话术 |
|------|---------|------|
| L1 | 再约一次 30 分钟（带他的真实运价表/一票真实单子） | "下次我想拿你家的真实数据试一遍导入，什么时候方便？" |
| L2 | 提供脱敏样本：1 份真实运价 Excel + 1 票货的全流程截图 | "能不能发我一份你现在的运价表格式，我按它调导入模板" |
| L3 | 指定试点对接人 + 约定 2 周试点范围（1 名员工 + 3 家客户） | "咱们挑一个销售试试，用 2 周真数据跑" |
| L4 | 签试点协议（免费或低价，含配合义务与反馈节奏） | "我准备一份试点约定，写清楚双方各做什么" |
| L5 | 付费意向：预付首月/年付折扣/书面报价确认 | "按你刚才说的价位，我出正式报价你确认" |

> 规则：**当场没拿到 L1 的访谈记为无效**（样本或表现有问题），不纳入决策统计。

## 8. 访谈后评分卡（24 小时内填完，每家一张）

5 个维度，各 0–5 分：

| 维度 | 0 分 | 5 分 | 得分 |
|------|------|------|------|
| 痛点强度 | 说不出具体事故 | ≥2 个带金额的事故，讲起来情绪明显 | |
| 替换意愿 | 不愿指定人、不愿动现有流程 | 当场指名对接人并约时间 | |
| 付费信号 | 四问全回避 | 给出区间且落在 $299+ 档 | |
| 数据配合度 | 不愿给运价表/不愿客户参与 | L2 及以上：主动提供真实数据 | |
| 传播潜力 | 无圈内影响 | 圈内活跃、有协会/同行群，愿意引荐 | |

**总分解读**：

- **20–25**：签下来，当灯塔案例做；
- **13–19**：保持联系，进 6 个月回访池；
- **<13**：感谢离开，复盘是样本问题还是产品问题。

## 9. 访谈后 24 小时内的动作

1. 填评分卡（趁记忆新鲜，别拖）；
2. 发感谢微信，**附上 TA 在访谈中提到的一个具体痛点的解决思路**（证明你听进去了，为 L2/L3 铺路）；
3. 录音转文字存档到 `docs/07-discovery/`（建目录），文件名：`partner-interview_YYYY-MM-DD_公司代号.md`，**公司名用代号**，防止泄露；
4. 每完成 2 家做一次对比复盘：新的共识、新的矛盾、提纲要改哪个问题。

## 10. 常见坑（每一条都毁过无数访谈）

1. **引导性提问**："你们是不是经常报错价？"——他只能答"是"。永远用开放式。
2. **把礼节当信号**：中国人对客人普遍客气，"挺好的"默认值为零信息。
3. **只访谈老板**：老板描述的流程和操作实际做的流程差 50%。两家都要见。
4. **现场改需求**：TA 说"能不能加个 XXX"，你不假思索答"可以"——下一句就是"那加完我看看"。正确回应："记下了，先弄清楚这个对你多重要再说。"
5. **Demo 讲太久**：讲得越久，反馈越假。让 TA 动手，你闭嘴。
6. **Excel 导入失败时辩解**：只说"对，这是我们现在最优先修的问题，你觉得理想的处理方式是什么？"——把故障变成需求采集。
7. **访谈报告只写结论**：必须带原话。原话是证据，结论是观点。

---

## 11. 决策规则（访谈全部结束后）

以 3–5 家为样本，按 Q1/Q2/Q3 三问统计：

| 结果组合 | 决策 |
|---------|------|
| ≥3 家 Q1+Q2+Q3 全通过 | **Go**：全力修 Excel 导入 → 签 2 家灯塔试点 → 按北极星（客户自助报价→订舱转化率）迭代 |
| Q1 通过，Q2 或 Q3 部分通过 | **包装 Pivot**：产品不动大方向，重新设计替换路径（先"看"后"订"）与定价结构（按票/按客户数） |
| Q1 通过但 Q2/Q3 全挂 | **换样本再验证一轮**（确认不是样本问题），仍挂则暂缓商业投入 |
| Q1 挂（说不出真实代价） | **冻结功能开发**，回到需求原点重新做客户发现 |

> 诚实条款：**不允许多访谈几家来"凑够"通过数。** 凑数访谈拿到的假阳性，会在 6 个月后变成流失率。
